## Primary insight

**Exchangeability-Failure Class (EFC).** After the subtractions above, the remaining unknown is not a missing place, not a missing converter, not an unjoined ledger, not a truncated coefficient, and not a monopolized channel.

It is this: **science treats draws from a calibration generator G_cal as exchangeable with the unobserved remainder generated by G_target. When G_cal ≠ G_target, increasing n on G_cal cannot identify G_target.** That is inconsistency, not variance. More of the same sample makes you more sure of the wrong process.

This is not spoken “selection bias” as a generic sermon. EFC is a search-protocol claim with a kill condition: **if adding samples from G_cal closes the gap, it was never EFC.**

### Operators inside EFC

1. **Generator split** — two processes that the field treats as one.
2. **More-n invariance** — extra draws from G_cal leave G_target unidentified.
3. **Template lock** — inferred parameters (isotopic priors, ancestor environment, biosignature libraries, biomass conversion factors) stay locked to G_cal.
4. **Strategic-sample admission** — when a field proposes *stratified* new sampling rather than random more-n, it is tacitly conceding non-exchangeability.

### Falsification rule

- If more spatial samples from the *same* process close it → undersampling (already claimed).
- If locating a converter closes it → TAC.
- If joining two existing ledgers closes it → JAC.
- If restoring omitted coefficients in the same model closes it → TPC.
- If re-reading the already-assigned channel for a second function closes it → CMC.
- If changing instrument coupling to an uncoupled DOF closes it → CIP.
- If watching longer closes it → CIC.
- **EFC is confirmed only if a draw from G_target changes the template, and a draw from G_cal does not.**

**Duals:** Undersampling = empty cells of one process. TPC = dropped terms of one model. PPC = extra hidden terms of one model. CMC = one function allowed per channel. CIP = the instrument cannot couple. **EFC = the calibration sample was generated by the wrong process.**
